# Agent instructions

When working on UI components, use the Storybook MCP tools before making assumptions about components, props, stories, or tests.

For this playground, validate that the MCP server can:

1. list available component documentation;
2. retrieve documentation for the `Button` component;
3. preview the `Primary` and `Secondary` stories;
4. run Storybook story tests when the MCP client supports the test toolset.

Do not invent component props. Check Storybook MCP documentation first.
